Roteiro sugerido para a demonstração
  1. Comece com "Comparar por: Região" e todos os eixos ligados. Mostre que o Sudeste ocupa a maior área.
  2. Desligue um eixo (por exemplo Desconto médio) e mostre que o formato muda: cada eixo é uma variável independente.
  3. Clique em "Embaralhar eixos". Os dados são os mesmos, mas a forma muda. Esse é o principal cuidado ao ler um radar.
  4. Troque a escala para "Mín–máx" e mostre como as diferenças ficam exageradas quando o pior grupo vai a zero.
  5. Mude para Vendedor ou Categoria e compare perfis. Feche com a tabela abaixo, para lembrar que o radar dá o formato e a tabela dá o número.
